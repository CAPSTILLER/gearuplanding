# GEAR landing page

Static site ready to host on a subdomain such as `app.yourdomain.com`.

## Files
- `index.html` — full landing page
- `assets/` — your images

## Deploy (free)
1. Zip this folder or push it to GitHub.
2. Drop it on [Cloudflare Pages](https://pages.cloudflare.com/), [Netlify](https://netlify.com/), or [Vercel](https://vercel.com/).
3. In your domain DNS, add a CNAME:
   - Name: `app` (or `go`)
   - Target: the host they give you (e.g. `your-project.pages.dev`)

Root domain can stay a plain page with a button that goes to the subdomain.
